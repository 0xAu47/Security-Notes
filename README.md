# Security-Notes

A public log of my cybersecurity learning journey — recaps written after each TryHackMe room (and other hands-on labs) I complete.

I'm starting from zero coding background, self-teaching toward a long-term goal of working in AI agent security. Each recap covers what the room taught, why it's actually relevant to real attack/defense work, and — honestly — whether I could explain it cold or I'm still shaky on parts of it. These are real notes from a real beginner, not polished write-ups dressed up to look like I used the most efficient method on the first try.

Longer reflections on some rooms are also posted on [Medium](https://medium.com/@goldenboy28.work).
